# Welcome to the LLG Extreme List!
This is the (currently unofficial) site for the Hardest LLG Levels List, which ranks the hardest levels in the Lawson Level Gallery, with placements and tiers for every Extreme difficulty level rated 3+ stars. The list also includes a leaderboard for the top players in the community.
